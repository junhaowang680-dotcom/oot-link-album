# oot-link-album

《塞尔达传说：时之笛》少年林克角色卡 —— 相册图鉴图床。

供 SillyTavern 角色卡「时之笛-少年林克」的 MVU 收集图鉴系统通过 jsdelivr CDN 调用。

## 目录结构

```
thumb/   缩略图（宽 400px / 场景 480px，WebP，用于相册九宫格）
full/    大图（原尺寸 WebP，用于点击放大查看）
```

## CDN 引用方式

```
https://testingcf.jsdelivr.net/gh/<GH_USER>/oot-link-album@main/thumb/<文件名>.webp
https://testingcf.jsdelivr.net/gh/<GH_USER>/oot-link-album@main/full/<文件名>.webp
```
